# PRD: 종스크롤 슈팅 게임 (제비우스 스타일)

## 1. 개요

### 1.1 프로젝트명
가칭 **"Sky Striker"** (변경 가능)

### 1.2 배경
1983년 남코의 고전 종스크롤 슈팅 게임 **제비우스(Xevious)**를 오마주하여, 순수 HTML5 + CSS3 + JavaScript(바닐라, 프레임워크 없음)로 브라우저에서 즉시 플레이 가능한 2D 종스크롤 슈팅 게임을 제작한다.

### 1.3 목표
- 별도 설치/빌드 과정 없이 브라우저에서 바로 실행되는 게임
- 제비우스의 핵심 정체성인 **"공중 사격(ZAP)"과 "지상 폭격(BLASTER)"의 이원화된 공격 시스템** 재현
- 반응형이지 않아도 되는 고정 캔버스 기반 아케이드 게임 (데스크탑 우선, 키보드 조작)

### 1.4 비목표(Out of Scope)
- 모바일 터치 최적화 (1차 버전에서는 제외, 추후 확장 가능)
- 멀티플레이어
- 서버/백엔드, 로그인, 랭킹 서버 저장 (로컬 스토리지 최고 점수 기록 정도만 지원)
- 사운드는 선택 사항(있으면 좋음, 필수는 아님)

## 2. 기술 스택

| 영역 | 기술 |
|---|---|
| 마크업 | HTML5 |
| 스타일 | CSS3 |
| 로직/렌더링 | JavaScript (ES2020+, 바닐라) |
| 렌더링 방식 | `<canvas>` 2D Context (`CanvasRenderingContext2D`) |
| 빌드 도구 | 없음 (모듈은 브라우저 네이티브 `<script type="module">` 사용) |
| 저장소 | `localStorage` (최고 점수) |
| 대상 브라우저 | 최신 Chrome, Edge (Chromium 계열) 기준 |

## 3. 게임 개요

### 3.1 장르
2D 종스크롤(수직 스크롤) 슈팅 (STG / 슈뮤업)

### 3.2 화면 구성
- 캔버스 해상도: **480 x 720px** (세로형, 종스크롤에 적합한 비율)
- 배경은 위에서 아래로 지속적으로 스크롤되며, 지형(강, 활주로, 기지 등)이 흘러 내려온다.
- 플레이어 기체는 화면 하단 영역에서 상하좌우로 자유 이동.

### 3.3 핵심 판타지
"하늘을 나는 적은 총으로, 땅 위의 적/시설은 폭탄으로" — 두 가지 다른 공격 수단을 동시에 운용하며 화면을 가득 채우는 적을 뚫고 나아가는 데서 오는 긴장감과 성취감.

## 4. 핵심 게임 메커니즘

### 4.1 플레이어 조작
| 입력 | 동작 |
|---|---|
| 방향키 (↑↓←→) 또는 WASD | 기체 이동 (화면 경계 내로 제한) |
| Z 또는 Space | ZAP! - 공중 목표물 대상 연사 사격 |
| X 또는 Shift | BLASTER - 지상 목표물 대상 폭탄 투하 |
| Enter | 게임 시작 / 재시작 |
| P | 일시정지 |

### 4.2 이원화된 공격 시스템 (제비우스 핵심 특징)
- **ZAP (공중 사격)**: 플레이어 정면으로 직선 발사되는 샷. 공중 유닛(적 전투기 등)만 명중 판정.
- **BLASTER (지상 폭격)**: 플레이어보다 약간 앞쪽 지점(진행 방향 기준 화면 위쪽)에 조준선(크로스헤어)이 표시되고, 그 지점에 폭탄이 투하됨. 지상 목표물(탱크, 기지, 포탑 등)만 명중 판정. 폭탄은 발사 후 일정 시간/거리 뒤 목표 지점에 도달하여 폭발.
- 공중 유닛에는 BLASTER가, 지상 유닛에는 ZAP이 통하지 않음 → 플레이어는 상황에 따라 두 공격을 동시/교차로 사용해야 함.

### 4.3 라이프 및 피격
- 시작 라이프: 3
- 플레이어 기체가 적 탄환 또는 적 기체와 충돌 시 라이프 1 감소 + 폭발 이펙트 + 짧은 무적 시간(약 2초, 깜빡임 표시)
- 라이프 0이 되면 게임 오버

### 4.4 스코어링
| 대상 | 점수(예시) |
|---|---|
| 소형 공중 적 | 100 |
| 대형 공중 적 / 편대 | 200~500 |
| 지상 포탑/탱크 | 150 |
| 지상 기지(대형 구조물) | 1000 |
| 스테이지 클리어 보너스 | 스테이지당 가산 |

- 최고 점수는 `localStorage`에 저장하여 타이틀/게임오버 화면에 표시.

### 4.5 파워업 (선택 기능, 2차 우선순위)
- 특정 지상 목표물 파괴 시 파워업 아이템 드롭
- 아이템 종류(예): 샷 강화(듀얼샷), 폭탄 강화(범위 확장), 스코어 보너스

## 5. 적 및 스테이지 설계

### 5.1 적 유형
1. **공중 적 (ZAP으로만 처치)**
   - 좌우 편대 이동형 (등장 후 정해진 궤적으로 이동하며 하강)
   - 플레이어 추적 사격형
   - 대형 보스급 공중 유닛 (스테이지 보스)
2. **지상 적 (BLASTER로만 처치)**
   - 고정 포탑 (제자리에서 플레이어 방향으로 사격)
   - 이동형 지상 유닛 (좌우 이동)
   - 대형 기지/시설 (다수 타격 필요, 스테이지 중간 보스급)

### 5.2 스테이지 구성
- 1차 버전 목표: **3개 스테이지** (지형 테마: 초원/기지 지대 → 협곡/강 지대 → 최종 요새)
- 각 스테이지는 고정된 스크롤 스크립트(시간/거리 기반 이벤트)로 적 등장과 지형 배치를 정의
- 각 스테이지 종료 시 보스전 발생, 보스 처치 시 다음 스테이지로 전환

### 5.3 배경/지형
- 스크롤 배경은 타일 반복 또는 긴 이미지 세로 스크롤 방식
- 지형 요소(활주로, 강, 기지 등)는 파괴 가능/불가능 오브젝트로 구분하여 배치

## 6. UI / HUD

- 좌측 상단: 현재 점수
- 우측 상단: 최고 점수(HIGH SCORE)
- 하단: 남은 라이프 아이콘, 현재 스테이지 번호
- BLASTER 조준 크로스헤어: 플레이어 전방에 항상 표시
- 타이틀 화면: 게임 제목, "PRESS ENTER TO START", 최고 점수
- 게임 오버 화면: "GAME OVER", 최종 점수, 최고 점수 갱신 여부, 재시작 안내

## 7. 비기능 요구사항

- **성능**: 데스크탑 크롬 기준 60FPS 유지 (동시 오브젝트 100개 내외 기준)
- **게임 루프**: `requestAnimationFrame` 기반, delta-time 사용으로 프레임 독립적 이동/속도 계산
- **충돌 판정**: AABB(사각형) 또는 원형 충돌 기반의 단순하고 성능 좋은 방식 사용
- **코드 구조**: 모듈(ES Module) 단위로 관심사 분리 (입력/렌더링/상태/충돌 로직 분리)
- **자산**: 초기 버전은 간단한 벡터/도형 기반 또는 최소한의 스프라이트로도 동작 가능하도록 설계 (이미지 자산 없이도 플레이 가능한 폴백 지원)

## 9. 리스크 및 검토 사항

- 제비우스 특유의 "숨겨진 지상 목표물" 요소는 재미 요소이나 난이도가 있어 1차 버전에서는 단순화(가시적 지상 적 위주)하고, 추후 확장 항목으로 남긴다.
- 자산(스프라이트/사운드) 확보 전략: 직접 제작한 단순 도형/픽셀 아트로 우선 대체하고, 추후 교체 가능하도록 렌더링 코드와 자산 경로를 분리한다.
